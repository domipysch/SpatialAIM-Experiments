# Section 01 — What AIM does (Fig. 2.1)

No scripts and no data: the overview figure is a schematic, drawn by hand in
Excalidraw. It is here so the four sections of the results are all in one place.

* drawing: `00_Obsidian/Excalidraw/figure_2_1.excalidraw.md` (`$AIM_VAULT`)
* render: `python -m aim_experiments.render 2_1` →
  `AIM-Overleaf/figures/fig_2_1.pdf`

Figures 2.2–2.4 are siblings of this one by design: they use its palette
(`aim_experiments.style`), its Helvetica at the same sizes, and the same
canvas width of 7.2 in at 300 units per inch, so the four print consistently at
the paper's 5.17 in text width.
